# Prueba guiada

**Estado:** Propuesta · **Área:** Resultados · **Prioridad:** Media · **Creada:** 2026-11-23

## Problema
Cada prueba tiene un número distinto de clics, así que los resultados no se pueden comparar entre sí.

## Propuesta
Modo "Prueba completa": "Haz 100 clics con el botón izquierdo", luego derecho, etc.
- Barra de progreso por botón.
- Al terminar, mostrar el [veredicto](veredicto.md).
- Mantener el modo libre actual como "Prueba rápida".

## Relación
Base para el [historial de sesiones](historial-de-sesiones.md): solo tiene sentido comparar sesiones con el mismo número de clics.

## Preguntas abiertas
- ¿Cuántos clics? ¿Configurable?
- ¿Incluir todos los botones o solo los que el usuario elija?
